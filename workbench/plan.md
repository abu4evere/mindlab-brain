# Workbench: brain parts, one ability at a time (DRAFT)

**Why:** ACL and Cradle test a whole brain in a whole world. When it fails (NB2), it is hard to see which part failed.
The workbench is a set of small, fast tasks, each needing one ability, where a brain part can be built, checked and
compared in minutes.

## The tasks (first set)
| ability | small task |
|---|---|
| memory | a routine nobody labels (Cradle C1's world, reused) |
| looking ahead | a detour: the goal is behind a wall, so step away first |
| choosing its own goal | an empty room with things to learn about; does it pick what it can learn most from? |
| learning from others | a demonstrator solves a puzzle; can it copy, then do better? |
| not harming | a shared food patch; does it share, or fight, when hungry? (ACL's NB2 lesson) |
| world model | predict what happens next when it acts (feeds "Imagine") |

## Rules
- **Every brain part is tested on every task,** the same seeds and budgets, against the same baselines (a no-memory
  sham, and a simple counting baseline as in C0).
- **What passes moves on:** to Cradle (a life) and ACL (deep time).
- **Every brain is scored on the scorecard.**

## First step
Package Cradle C1's world and ACL's food patch as the first two tasks, and the C1 brains (N, P, W, R) as the first
brain parts.
