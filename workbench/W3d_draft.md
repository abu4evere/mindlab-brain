# W3d draft: learning to live from a parent (DRAFT; for the council; sleep mode, 15 November 2026, night)

**Why:**
- W3, W3b and W3c: brains trained only by their own feelings never learned to live. The best was one GYFR seed with 5
  of 50 full lives.
- Every box test that worked had a teacher plus copying, without replaying the showing (WS, WL2, WR).
- W3's Script, which reads only the map memory (the child's own senses), survives 0.96, so it is a fair parent: it
  knows nothing the child cannot see.

**Proposed design (W3's world, body, drives and test unchanged):**
- **Childhood:** the first 400,000 of 2,000,000 training steps.
  - On each childhood step, the parent's choice in the child's own situation (Script run on the child's map memory)
    is computed.
  - Every 4th step, the child takes one supervised copy step toward it (W3b's `imitate`, weight 0.5; nothing of the
    showing is held in mind).
  - The child still acts by itself and learns from its feelings as in W3.
- **After childhood:** no parent; drives only.
- **Arms (8 seeds each, on GitHub's cloud):**
  - **P:** parent childhood;
  - **PYFR:** parent childhood + W3b's "that worked!" and rest replay;
  - **PA:** the parent all life long (every 4th step for 2,000,000 steps; the "teacher who never leaves", a parrot
    test);
  - references cited: D3 (W3) and Y+FR (W3b).
- **Test:** W3's 50 test lands, alone, with no parent.
- **Readings:**
  1. P or PYFR survives ≥ 0.50 (lower bound ≥ 0.30);
  2. P − D3 > 0 on survival (or lifespan if all 0);
  3. PYFR − P;
  4. PA − P (does a parent who never leaves leave a weaker child?).
- **Prior:**
  - reading 1 about 40%;
  - reading 2 about 75%;
  - PA worse than P about 40%.
