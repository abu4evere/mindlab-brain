# Scorecard: an honest measure of autonomy, and of the features theories tie to consciousness (DRAFT)

**Why:** without a fixed yardstick, "the mind is getting more autonomous" is a feeling, not a finding. The scorecard is
built once, frozen, and then applied the same way to every brain in ACL, Cradle and the workbench.

## Part A: autonomy (behavioural tests, each pass or fail with an interval)
1. **Own goals:** it pursues a goal nobody set, and switches goals when the world changes.
2. **Looking ahead:** it acts for a payoff several steps away (a detour task).
3. **Learning from its own mistakes:** it does better on the second try after a failure, with no teacher.
4. **Learning from others:** it copies a better way it has seen, and improves on it.
5. **Curiosity:** it explores what is new when nothing forces it to.
6. **Holding a project:** it keeps a multi-step plan going across interruptions.

## Part B: indicator features named by published theories of consciousness
Drafted from the indicator-properties approach in the literature (for example Butlin, Long et al., 2023, "Consciousness
in Artificial Intelligence"). Each item is a *feature of the system*, checked in the code and in behaviour, **never a
claim that it is conscious.**
- **Global workspace:** a limited shared stage that many parts write to and read from.
- **Recurrent processing.**
- **A world model, and the agent as part of it.**
- **A self-model:** it knows what it knows. Tested with an opt-out task: it skips a trial when unsure, and does better
  on the trials it keeps.
- **Attention that it monitors and controls** (attention schema).
- **Agency and embodiment:** it learns how its own acts change what it senses.
